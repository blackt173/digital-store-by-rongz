# 🛒 Digital Store Telegram Bot

Telegram Bot សម្រាប់លក់ទំនិញឌីជីថល (Digital Products) ជាមួយនឹងប្រព័ន្ធទូទាត់ប្រាក់ស្វ័យប្រវត្តិតាមរយៈ **Bakong KHQR**។

## ✨ លក្ខណៈពិសេស (Features)
- 🛍️ ទិញទំនិញឌីជីថលស្វ័យប្រវត្តិ ២៤/៧
- 💳 ទូទាត់ប្រាក់តាមរយៈ **Bakong KHQR** ស្វ័យប្រវត្តិ (Check Transaction MD5)
- 🧾 បង្កើតវិក្កយបត្រ PDF ស្វ័យប្រវត្តិ (Auto-generated PDF Invoices)
- 🌐 គាំទ្រពីរភាសា៖ ភាសាខ្មែរ 🇰🇭 និង ភាសាអង់គ្លេស 🇺🇸
- 🛡️ ប្រព័ន្ធការពារ Anti-Spam Middleware
- 📊 ផ្ទាំងគ្រប់គ្រងសម្រាប់ Admin (Dashboard, ស្តុក, របាយការណ៍លក់)

## 📦 ការដំឡើង និងដំណើរការ (Quick Start)

### ១. ដំឡើងបណ្ណាល័យ (Requirements)
```bash
pip install -r requirements.txt
```

### ២. បង្កើតឯកសារ `.env`
ចម្លង `.env.example` ទៅជា `.env` រួចបំពេញព័ត៌មាន៖
```bash
cp .env.example .env
```

### ៣. ដំណើរការ Bot
```bash
python main.py
```
